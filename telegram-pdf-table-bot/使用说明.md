# PDF / 照片表格转 Excel Telegram Bot 使用说明

这是一个**独立的 Telegram bot**（@PDFTOEXCELNICBot），和 Fastener 下单 bot 分开：不同的 BotFather token、不同的文件夹、不同的授权名单。

同事在私聊里发一个 **PDF 文件**或一张**表格照片/截图**，bot 回一个 Excel 文件。

## 第一次设置（管理员在主机电脑上做一次）

1. 在 Telegram 打开 @BotFather，发送 `/newbot`，建一个**新的** bot。不要用 Fastener bot 的 token。
2. 双击 `Setup.cmd`，把 BotFather 给的 token 粘贴进去（输入时不显示）。token 用 Windows DPAPI 加密保存在 `token.dpapi`。
3. Setup 窗口会显示 bot 链接和 `/pair 配对码`。在 Telegram 打开这个 bot，发送整行 `/pair 配对码`，成为管理员。
4. 双击 `Start.cmd`。看到绿色 `ONLINE: @你的bot名` 就可以用了。

不要把 token 贴到任何聊天或 AI 对话里。

## 授权同事

- 同事在 bot 里发 `/id`，把数字 ID 发给管理员。
- 管理员发 `/allow 数字ID` 开通，`/remove 数字ID` 取消。
- 只接受私聊，群组消息会被忽略。

## 发 PDF

- 把 PDF **以文件形式**发给 bot。
- 只支持**有文字**、表格**有框线**的 PDF（从 Excel、Word 或系统导出的那种）。
- 扫描版 PDF 不支持，请改为发这一页的照片或截图。

## 发照片 / 截图

- 直接发照片，或者用回形针 > **File** 发图片文件（JPG、PNG 等）。
- **用 File 发最准**：用 Photo 发时 Telegram 会压缩图片。
- 拍照要点：正对表格拍、光线充足、整张表在画面里、对好焦。
- 支持印刷的英文和中文，不支持手写。
- 照片在主机电脑上**离线识别**，不会上传到其他服务。每张照片大约 20–30 秒，bot 会先回复 “Reading the photo”。
- 每张照片回一个 Excel；一次发多张照片会各自回一个 Excel。
- 文字识别可能认错字或漏掉空格（例如 `SCH80CPVC`），**使用前请对照照片核对**，尤其是数量。

## Excel 的内容

- 所有表格按顺序放在同一个 sheet。
- 表格上方的文字（如 `PO.20288`、`CPVC :`、`DC: CLEAR PVC`、`SUPPORT`）单独成一行。
- 续页重复的表头会去掉；`第 1 页，共 4 页` 这类页码不写入。
- 纯数字（如 `5667`、`1,260`）写成 Excel 数字；带单位的（如 `10 LGH`、`1,260PCS`、`320 个`）保持文字。
- 文件上限 20 MB（Telegram bot 的下载限制）。

## 日常操作

- 登录 Windows 后会自动启动（启动文件夹里的快捷方式，隐藏运行，不会弹窗）。
- 桌面上的 `Start PDF to Excel Bot` 可以手动启动；`Start.cmd` 启动，`Stop.cmd` 停止，`Restart.cmd` 重启。
- 主机电脑必须开机、登录、联网。
- 收到的 PDF、照片和生成的 Excel 保存在 `outputs\`（私密业务资料，不要外传）。
- 运行记录在 `bot.log`，错误在 `error.log`。

## 需要的软件

- Python 3（本机已装 3.13）
- `python -m pip install --user -r requirements.txt`（PyMuPDF、openpyxl、OpenCV、NumPy、RapidOCR、Pillow）
